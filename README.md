# mahhie393.com

Personal portfolio site of Mahiro Sakaue. Built with [Astro](https://astro.build) and Tailwind CSS, prerendered to static files and served by Cloudflare Workers static assets at https://mahhie393.com.

The site is under construction: the repository currently holds the tooling, and the pages are placeholders.

## Requirements

- Node.js 24 (pinned in `.node-version`; use `nvm use`)
- pnpm 11 through corepack (pinned in `package.json` `packageManager`)

```sh
nvm use
corepack enable
pnpm install   # also registers the git hooks (lefthook)
```

## Commands

| Command | Action |
| --- | --- |
| `pnpm dev` | Dev server at http://localhost:4321 (`astro dev --background` to run it detached) |
| `pnpm check` | Biome (format, lint, imports), Prettier (`.astro`), `astro check` (types) |
| `pnpm build` | Build the site into `dist/` |
| `pnpm preview` | Serve `dist/` with `wrangler dev` at http://localhost:8787, as Cloudflare would |
| `pnpm deploy` | Deploy `dist/` with Wrangler (needs `wrangler login`) |

## Workflow

- Work on a branch and open a pull request; `main` accepts changes only through pull requests with a green CI run (`.github/workflows/ci.yml` runs `pnpm check` and `pnpm build`).
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/) without scopes, enforced by commitlint in the `commit-msg` hook. See `.claude/vaults/commit.md` for the conventions in use.
- The `pre-commit` hook formats staged files: Biome for JS, TS, JSON and CSS; Prettier for `.astro`. Linting runs in CI only.
- Deploys are planned through Cloudflare Workers Builds from `main`; configuration lives in `wrangler.jsonc`.

## Layout

```text
src/pages/        pages (file-based routing)
src/styles/       global.css (Tailwind entry)
public/           static assets served as-is
.github/          CI workflow and the ruleset for main
.claude/          Claude Code commands (/commit, /summarise), guard hook and vaults
```
